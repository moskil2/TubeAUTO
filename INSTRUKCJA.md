# TubeAUTO - instrukcja instalacji krok po kroku

Potrzebne są dwie aplikacje: **Shizuku** i **TubeAUTO**. Komputer nie jest potrzebny.
Na zrzutach czerwona ramka pokazuje, co trzeba stuknąć.

## Część 1. Shizuku (robi się raz)

Najpierw zainstaluj **[Shizuku z Google Play](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api)**.

Kroki 5-13 zrób w ciągu 3 minut. Jeśli pojawi się "Shizuku nie odpowiada" albo zniknie
powiadomienie Shizuku, zacznij jeszcze raz od kroku 5.

| Krok | Ekran |
|---|---|
| **1.** Otwórz **Ustawienia** telefonu i stuknij **Telefon - informacje**. | <img src="screenshots/instrukcja/01.jpg" width="270" alt="Krok 1" /> |
| **2.** Stuknij **Informacje o oprogramowaniu**. | <img src="screenshots/instrukcja/02.jpg" width="270" alt="Krok 2" /> |
| **3.** Stuknij **7 razy** w **Numer wersji**. Telefon może poprosić o kod blokady ekranu. | <img src="screenshots/instrukcja/03.jpg" width="270" alt="Krok 3" /> |
| **4.** Gotowe: na dole **Ustawień** pojawiły się **Opcje programisty**. Jeśli były już wcześniej, kroki 1-3 możesz pominąć. | <img src="screenshots/instrukcja/04.jpg" width="270" alt="Krok 4" /> |
| **5.** Otwórz **Shizuku** i stuknij **Parowanie**. | <img src="screenshots/instrukcja/05.jpg" width="270" alt="Krok 5" /> |
| **6.** Jeśli widać ten ekran, stuknij **Ustawienia powiadomień**. Jeśli nie, przejdź do kroku 9. | <img src="screenshots/instrukcja/06.jpg" width="270" alt="Krok 6" /> |
| **7.** Włącz **Zezwalaj na powiadomienia**. | <img src="screenshots/instrukcja/07.jpg" width="270" alt="Krok 7" /> |
| **8.** Wróć strzałką. | <img src="screenshots/instrukcja/08.jpg" width="270" alt="Krok 8" /> |
| **9.** Stuknij **Opcje developerskie**. | <img src="screenshots/instrukcja/09.jpg" width="270" alt="Krok 9" /> |
| **10.** Stuknij sam napis **Debugowanie bezprzewodowe** (nie przełącznik obok). | <img src="screenshots/instrukcja/10.jpg" width="270" alt="Krok 10" /> |
| **11.** Jeśli u góry jest **Wyłączone**, włącz przełącznik i stuknij **Zezwól**. Potem stuknij **Sparuj urządzenie przy pomocy kodu parowania**. | <img src="screenshots/instrukcja/11.jpg" width="270" alt="Krok 11" /> |
| **12.** Pokaże się 6-cyfrowy kod. Zapamiętaj go i **nie zamykaj** tego okna. | <img src="screenshots/instrukcja/12.jpg" width="270" alt="Krok 12" /> |
| **13.** U góry ekranu pojawi się powiadomienie Shizuku **Znaleziono usługę parowania** (jeśli zniknęło, przesuń palcem od samej góry ekranu w dół). Stuknij w nim **Wprowadź kod parowania**, wpisz kod z kroku 12 i stuknij **Wyślij**. | <img src="screenshots/instrukcja/13.jpg" width="270" alt="Krok 13" /> |
| **14.** Wróć do **Shizuku** i stuknij **Start**. | <img src="screenshots/instrukcja/14.jpg" width="270" alt="Krok 14" /> |
| **15.** Shizuku się uruchamia. Okno zamknie się samo po 3 sekundach. Gotowe: Shizuku działa. | <img src="screenshots/instrukcja/15.jpg" width="270" alt="Krok 15" /> |

## Część 2. TubeAUTO

| Krok | Ekran |
|---|---|
| **16.** Pobierz **[najnowszy TubeAUTO](https://github.com/moskil2/TubeAUTO/releases/latest)** (plik `.apk`), otwórz go i stuknij **Zainstaluj**. | <img src="screenshots/instrukcja/16.jpg" width="270" alt="Krok 16" /> |
| **17.** Otwórz **TubeAUTO** i stuknij **Enable in Android Auto**. | <img src="screenshots/instrukcja/17.jpg" width="270" alt="Krok 17" /> |
| **18.** Stuknij **Zawsze zezwalaj**. | <img src="screenshots/instrukcja/18.jpg" width="270" alt="Krok 18" /> |
| **19.** Włącz **Przyznaj uprawnienie**. | <img src="screenshots/instrukcja/19.jpg" width="270" alt="Krok 19" /> |
| **20.** Wróć strzałką. | <img src="screenshots/instrukcja/20.jpg" width="270" alt="Krok 20" /> |
| **21.** Stuknij jeszcze raz **Enable in Android Auto**. | <img src="screenshots/instrukcja/21.jpg" width="270" alt="Krok 21" /> |
| **22.** Stuknij **Aktualizuj**. | <img src="screenshots/instrukcja/22.jpg" width="270" alt="Krok 22" /> |
| **23.** Poczekaj, aż skończy się instalacja. Jeśli TubeAUTO się zamknie, otwórz je ponownie. | <img src="screenshots/instrukcja/23.jpg" width="270" alt="Krok 23" /> |
| **24.** Gotowe: na dole jest **Ready**. | <img src="screenshots/instrukcja/24.jpg" width="270" alt="Krok 24" /> |

## Część 3. Auto

**25.** Podłącz telefon do auta i na ekranie auta otwórz **TubeAUTO**.

## Później

- **Po restarcie telefonu** Shizuku jest wyłączony. Do samego oglądania w aucie nie jest potrzebny.
  Potrzebny jest tylko przy aktualizacji TubeAUTO: wtedy otwórz Shizuku i stuknij **Start**
  (parowania nie trzeba powtarzać).
- **Po każdej aktualizacji TubeAUTO** zrób jeszcze raz kroki 17-24.
